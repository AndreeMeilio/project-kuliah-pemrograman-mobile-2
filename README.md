# 🎓 Pemrograman Mobile 2 — Course Assignments

Repository ini digunakan untuk mengumpulkan **latihan dan tugas** yang telah dikerjakan dalam mata kuliah **Pemrograman Mobile 2**.  
Setiap latihan, tugas, atau proyek akhir akan ditempatkan pada **branch yang berbeda**, agar mudah dikelola dan dipantau perkembangannya.

---

## 🧩 Struktur Repository

Berikut adalah ketentuan penamaan branch untuk setiap jenis pekerjaan:

| Jenis | Format Branch | Contoh Branch | Deskripsi |
|-------|----------------|----------------|------------|
| Latihan | `[nama]-practice` | `counter-app-flutter-practice` | Berisi latihan 2: *Flutter Counter App* |
| Tugas | `[nama]-assignment` | `calculator-app-assignment` | Berisi tugas pembuatan *Calculator App* |
| Proyek | `[nama]-project` | `final-app-project` | Berisi proyek akhir mata kuliah *Final Project App* |

---

## 🚀 Cara Mengakses Setiap Latihan / Tugas / Proyek

1. Clone repository ini terlebih dahulu:
   ```bash
   git clone https://github.com/username/nama-repo.git
   cd nama-repo

2. Lihat daftar semua branch yang tersedia
   ```bash
   git branch -a

3. Pindah ke branch latihan, tugas, atau project yang ingin diakses:
   ```bash
   git checkout counter-app-flutter-practice


## 🧠 Catatan Tambahan

Setiap branch hanya berisi satu latihan, tugas, atau proyek tertentu.

Perubahan atau update akan dicatat melalui commit di branch terkait.

Branch utama (main atau master) hanya digunakan untuk dokumentasi dan panduan umum seperti README ini.
